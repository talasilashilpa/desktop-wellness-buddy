# Desktop Wellness Buddy demo

This is a short, local-only demonstration of the public build.

## Start

From PowerShell in this folder:

```powershell
powershell -ExecutionPolicy Bypass -File .\Run-Demo.ps1
```

The demo does not create a scheduled task, change Windows startup, call an API, or access a company system.

## Try these interactions

- Watch the mascot walk with its six-pose sprite cycle.
- Double-click it for a rotating office-safe joke.
- Right-click it for water, break, check-in, focus, and mood actions.
- Click the close button to hide it; the next scheduled reminder can bring it back.
- Use `--pomodoro` instead of `--solid` if you want the optional focus timer.

## What success looks like

The generic robot appears, walks without cropped hands or feet, pauses for a thought bubble, and remains local to the Windows desktop. No account, network connection, or personal asset is required.
